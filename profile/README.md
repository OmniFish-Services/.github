# Support Portal for OmniFish clients

> [!NOTE]
> We're transitioning to a new **Customer Portal** at **https://omnifish.jitbit.com**. Please follow there if you already have access to it.
> 
> New OmniFish customers will get access to the new portal automatically.
> 
> Existing customers can continue using the Support Portal here on GitHub as before or may request access to the new portal by raising a support ticket with the request.
>
> Currently, the address https://support.omnifish.ee forwards to this Support Portal here but we'll eventually change it to forward to the new Customer Portal. If you're going to continue using this Support Portal on GitHub, bookmark this URL to find it later: https://github.com/OmniFish-Services 

To raise issues for the OmniFish Support team:

* Go to [Repositories](https://github.com/orgs/OmniFish-Services/repositories) and click on the repository with your company name

To view your existing issues:

* Open the [Issue Dashboard](https://github.com/issues?q=is%3Aopen+is%3Aissue+archived%3Afalse+user%3AOmniFish-Services+sort%3Aupdated-desc)
